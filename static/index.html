Example URL. Open the tracker on its final HTTPS address to copy the deployment callback.

Connect Microsoft Entra ID
  1. Register a single-tenant web application in the Microsoft Entra admin center.
  2. Under Authentication, add the callback URL shown above as a Web redirect URI.
  3. Copy the directory (tenant) ID and application (client) ID. Create a client secret and copy its value.
  4. Update the server's .env with OIDC_ENTRA_TENANT_ID, OIDC_CLIENT_ID, OIDC_CLIENT_SECRET, and OIDC_REDIRECT_URI. Set TRACKER_AUTH_MODE=test and run docker compose up -d.
  5. Open the HTTPS tracker and select Test sign-in. Confirm the account and role displayed below. After a successful test, set TRACKER_AUTH_MODE=required and run docker compose up -d again.
Connect Authentik or another OIDC provider
  1. Create a confidential OIDC application, choose an RSA signing key, and add the same HTTPS callback URL.
  2. Set OIDC_ISSUER_URL to the provider's exact issuer URL. Leave OIDC_ENTRA_TENANT_ID empty. Set the client ID, secret, and redirect URI in .env.
  3. Start in test mode, verify the account and role, then set the mode to required.
